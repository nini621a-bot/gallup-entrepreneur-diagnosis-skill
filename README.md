# 盖洛普创业优势诊断 Skill

妮妮Elvira的优势创业解读 Skill，帮助用户结合个人优势报告探索创业方向、适配的工作方式和当前创业问题。

## 内容

- `SKILL.md`：欢迎引导、报告识别、优势画像、创业适配地图、专项诊断与行动计划。
- `references/cliftonstrengths-domains.md`：盖洛普 CliftonStrengths 四大领域参考。

## 支持的报告

- **CliftonStrengths（盖洛普）**：重点看 Top 10，并结合 Top 11–15；具备足够排序信息时分析才干互动模式。
- **APESK 天赋发现测试**：可作为没有盖洛普报告时的初步参考。它不是盖洛普测试；Skill 按 APESK 报告自身字段解读，不进行跨体系换算，也不生成盖洛普专属的才干互动模式。

报告只能提供自我探索线索，创业方向和行动建议仍需结合用户经历、市场、资源与实际验证。
